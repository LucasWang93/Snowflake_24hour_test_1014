# challenge-intake

Read all relevant task files, README, repository instructions, starter code,
dependency manifests, tests, and submission instructions. Inspect AI-use rules first:
stop AI-assisted challenge work if forbidden; resolve unclear permission before coding.
Record authoritative sources for functional/nonfunctional requirements, hidden
constraints, prohibited tools, required deliverables, evaluation criteria, and deadline.
Separate facts, assumptions, and open questions in docs/CHALLENGE_SPEC.md. Do not
assume RAG, agents, services, credentials, or a particular stack.
Create stable requirement IDs and a requirement-to-test matrix: source, acceptance
criterion, planned test/evaluation, observed evidence, status. Create an ordered
vertical-slice plan with acceptance criteria, prioritizing a runnable end-to-end path.
Update docs/PROGRESS.md and record Gate A evidence only when rules are understood.
